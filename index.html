What is the Game of Life?

The Game of Life is a cellular automaton created by mathematician John Conway. It is not a game with winners; it is a grid of cells that evolves generation by generation using a few simple rules.

The rules

  • A live cell with fewer than two live neighbours dies.
  • A live cell with two or three live neighbours survives.
  • A live cell with more than three live neighbours dies.
  • A dead cell with exactly three live neighbours becomes alive.

Start advances the simulation, Stop pauses it, and Reset creates a fresh random grid. Grid size can be set from 10×10 up to 100×100.
